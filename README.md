# Вебкрафт

Учебник создания сайтов на русском: 36 уроков, 9 модулей, 81 термин, 6 проектов и песочница HTML/CSS/JavaScript.

Статический сайт без серверных зависимостей. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → /(root).

Прогресс и черновики хранятся локально в браузере.
